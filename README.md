# AirSafe

**Turning real-time air quality into personalized exposure insights and safer everyday decisions.**

AirSafe is a web application that helps people understand how air pollution may affect planned outdoor activities and recommends actions based on air quality, activity type and duration.

## Planned Features

- Current air quality dashboard
- Estimated personal exposure score
- Personalized recommendations
- Air quality forecasts
- Potentially safer outdoor time windows
- Pollution-aware route comparisons
- Exposure history and alerts

## Technology Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **External Data:** OpenWeather Air Pollution API
- **Containers:** Docker
- **CI/CD:** GitHub Actions
- **Cloud:** AWS
- **Infrastructure as Code:** Terraform

## Repository Structure

- `client/` — frontend application
- `server/` — backend API and recommendation engine
- `terraform/` — AWS infrastructure configuration
- `.github/workflows/` — CI/CD workflows
- `docs/` — architecture and API documentation

## Development Workflow

All changes should be developed on separate branches and submitted through pull requests targeting `main`.
